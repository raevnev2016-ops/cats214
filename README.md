# КОТОНИНДЗЯ — динамичная мини-игра для Чёрной пятницы Стадикэтс

Откройте `index.html` в браузере или разместите файлы репозитория на GitHub Pages.

**Игровая механика:** 45 секунд; свайпать полезные карточки, избегать вредных; 3 жизни; цель — 500 очков. За последовательные попадания предусмотрены комбо, золотые карточки приносят 100 очков. Выбор «История» / «Обществознание» меняет тематические названия, расцветку и ссылку на курс.

**Публикация:** создать репозиторий GitHub → загрузить `index.html`, `style.css`, `game.js` и `assets/` → Settings → Pages → Deploy from a branch → main / root. После публикации проверить игру на iPhone/Android в браузере Telegram.

**Покупка:** обе ссылки с UTM предоставлены заказчиком и находятся в `game.js`. Скидка 20% на абонементы полугодовых курсов; на каждый второй и последующий предмет скидка 700 ₽/месяц вместо 500 ₽/месяц. Проверить реальное сочетание условий с командой продаж перед публикацией.

**Примечание:** используется оригинальная механика нарезки объектов в духе аркад, без чужих названий, логотипов или графических ресурсов.
